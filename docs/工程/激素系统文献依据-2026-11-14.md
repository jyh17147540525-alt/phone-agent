# 激素系统：把参数落到文献（2026-11-14）

> 目标：这个角色的四条激素，**激发条件、时程、幅度、行为效应**都能指到论文或权威综述上，
> 而不是"我觉得两小时比较合适"。
>
> 结论先说：四条里 **三条的半衰期换短了很多**（催产素 24h → 45min 最狠），
> 另外补了两条真实存在、之前完全没有的机制（HPA 负反馈、昼夜反应性）。
> 全部离线验证通过：**806 个 JUnit 用例 + 4311 个逻辑用例 + 14/14 校验脚本**。

---

## 1. 立场：我们建的是行为状态，不是血浆浓度

这一点必须先说清，否则后面每个数字都会被误读成"血检值"。

人身上的信号分三层，时间尺度差三个数量级：

| 层 | 时间尺度 | 例子 | 我们能不能建模 |
|---|---|---|---|
| 神经递质（相位） | 毫秒–秒 | 多巴胺 burst、去甲肾上腺素放电 | **不能**。最小粒度是一条消息（几十秒到几分钟） |
| 神经递质（紧张性） | 秒–分钟 | 蓝斑紧张性放电、5-HT 释放 | 只能取"行为余韵" |
| 内分泌（激素） | 分钟–小时 | 皮质醇、催产素、睾酮 | **能**，直接用文献时程 |

`Hormones(dopamine, serotonin, oxytocin, cortisol)` 是 0..100 的**行为状态**，
它要回答的问题是"这条消息该怎么回"，不是"现在血清里有多少 nmol/L"。

所以每个参数落进两类之一，并且在代码里**明确标注是哪一类**：

- **文献值**：内分泌的时程、昼夜形状、周转时间 —— 这些外周血能测，可以直接搬；
- **产品量**：中枢多巴胺/血清素的活动量 —— 从外周血推不出来，只能借**机制方向**，
  时间常数取"行为余韵"，并写明它是标定值而不是测量值。

> 把两类混着写、笼统说"这是文献说的"，比不写出处更糟 —— 后来人不敢动，
> 也没法判断哪一条可以动。

## 2. 四条激素的完整依据

### 2.1 皮质醇（HPA 轴终产物）

**激发条件**（真实的生理通路）

下丘脑室旁核分泌 CRH → 垂体前叶分泌 ACTH → 肾上腺皮质束状带合成皮质醇。
心理应激（不是物理伤害）也会走这条路，这就是"被骂一句为什么会紧张"的物质基础。

**时程**（这是本次改动最大的依据来源）

| 参数 | 数值 | 出处 |
|---|---|---|
| 血浆半衰期 | **66 分钟**（正常水平；大剂量时因结合球蛋白饱和会延长） | Holland-Frei《Pharmacokinetics of Corticosteroids》 |
| 心理应激峰值 | **20–30 分钟** | Kirschbaum/Pirke/Hellhammer 1993（TSST 原始文献） |
| 回到基线 | **60–90 分钟** | 同上 |
| 皮质醇觉醒反应（CAR） | 醒后 **30–45 分钟**，平均升 **50–60%** | Adam 2017 综述 |

**幅度**（血清，nmol/L）

| 时点 | 范围 | 均值 |
|---|---|---|
| 08:00–09:00 | 138–690 | **459.6 ± 235.2** |
| 16:00–17:00 | 约 150–300 | — |
| 00:00–02:00（谷） | 0–276（多数 50–140） | — |

临床判据旁证：早晨 >300 nmol/L 可排除肾上腺皮质功能不全 —— 说明"晨峰数百"是常态量级。

**行为效应**

- 急性、中等幅度：警觉提升、威胁线索优先加工、说话变短变正式；
- 慢性升高：反刍、睡眠变差、HPA 轴反应性钝化；
- 我们的映射：**防备、想缩起来、开不动玩笑**（`toneDelta()` 里就是这几条）。

**我们怎么用**

1. 半衰期 66min = **1.1 小时**（`HormoneKinetics.CORTISOL_PLASMA_HALF_LIFE_MINUTES`）；
2. **不把日间曲线加到状态上**。理由见 3.2 —— 晨峰是正常生理高峰，不是"她很紧张"；
3. 加 HPA 负反馈（见 3.1）。

### 2.2 催产素

**激发条件**

室旁核/视上核的大细胞神经元 → 垂体后叶释放入血；同时有树突释放（局部作用，影响社会行为）。
触发它的主要是**安全的社会接触**：轻柔抚摸、拥抱、哺乳、性、以及"被信任"这类社会信号。

关键细节：**抚摸要持续约 20 秒**才明显触发（"20 秒拥抱"的生理依据）。
短促的一下不够 —— 这解释了为什么"敷衍地抱一下"和"真的抱住"体感完全不同。

**时程**

| 参数 | 数值 | 说明 |
|---|---|---|
| 血浆半衰期 | **3–6 分钟**（多数报告 1–6 min） | 静脉给药测定 |
| 鼻喷后的行为窗口 | **30–60 分钟最明显**，常延到 1 小时以上 | 受体后信号，不是血浆浓度 |

这两个数字看起来矛盾，其实不矛盾：**血浆清得快，受体后信号慢**。
所以我们用的是**行为半衰期 45 分钟**，并在代码里明说它不是血浆值。

**行为效应**

- 信任、亲近、愿意靠近；降低杏仁核对威胁面孔的反应；
- 有"阴暗面"：增强内群体偏私（De Dreu 2010）—— 对"自己人"更好，对"外人"更防。
  我们没有"外人"，所以这一支暂时用不上，但值得记着：催产素不是"善良激素"。

**我们怎么用**

- 半衰期 24h → **45 分钟**。这是本次最大的一处改动。
- 旧的 24 小时意味着"一次拥抱影响一整天"，而按文献，它的余韵是**半小时到一小时**。
- 20 秒阈值写进 `TOUCH_THRESHOLD_SECONDS`，目前只用于文案判断 —— 一条消息测不出"抱了几秒"。

### 2.3 多巴胺

**激发条件**

中脑 VTA / 黑质致密部的多巴胺神经元，相位性放电编码**奖励预测误差**（RPE）：
结果好于预期 → burst；差于预期 → dip。

这是"被夸会高兴"的机制，但也带来一个常被搞错的点：

> **多巴胺管"想要"（wanting），不管"快乐"（liking）。**
> 快乐的物质基础主要是阿片系统。多巴胺缺失的动物仍然会表现出"喜欢甜味"的面部反应，
> 只是不再"去拿"。所以我们在代码里把它映射成**"被点亮、期待、想做点什么"**，
> 而不是"开心"—— 这个措辞是照着机制写的。

**时程**

| 参数 | 数值 | 说明 |
|---|---|---|
| 相位 burst 潜伏期 | **100–200 毫秒** | 我们建不了，粒度差三个数量级 |
| 行为余韵（我们定的） | **30 分钟** | 产品量，不是测量值 |

**行为效应**：动机、探索、话多、跳脱；高位 + 低血清素 = 亢奋但不稳（这条已经在测试里钉住）。

**我们怎么用**：半衰期 2h → **30 分钟**。

### 2.4 血清素（5-HT）

**激发条件**

中缝核 → 全脑投射。合成限速酶是色氨酸羟化酶，所以**色氨酸可用量**直接决定合成速率 ——
这就是"急性色氨酸耗竭"（ATD）实验的原理：给受试者不含色氨酸的氨基酸混合物，
几小时内把 5-HT 合成压下去。

**时程**

| 参数 | 数值 | 说明 |
|---|---|---|
| ATD 后情绪最低点 | **约 6 小时** | 耗竭是渐进的 |
| 恢复 | **24 小时后检测不到差异** | 说明周转是 5–7 小时量级 |

**关键限定（很重要）**：ATD 在**健康人**身上只让情绪轻微下降，效应量小、个体差异大。
所以这一条只能当"慢变量"，不能当"一次争执就让血清素崩"。

**行为效应**：情绪稳定、冲动控制、减少反刍；低 → 易怒、钻牛角尖、对同一件事反应更大。

**我们怎么用**：半衰期 8h → **6 小时**（在 5–7h 的周转区间内取整）。

## 3. 两条新机制

### 3.1 HPA 负反馈（规则 8）

**机制**：皮质醇本身通过糖皮质激素受体（GR）负反馈抑制下丘脑 CRH 与垂体 ACTH，
同时肝脏清除加快。净效果是**皮质醇越高，回落越快**。

这与直觉相反（"越高越难下来"），但测量结果很明确：TSST 之后不管峰值多高，60–90 分钟必回基线。

**实现**（`HormoneEngine.advance`）：

```
cortisolLoad   = clamp((cortisol - 50) / 50, 0, 1)        // 50→0，100→1
有效半衰期      = 基础半衰期 / (1 + 0.6 × cortisolLoad)     // 100 分时 = 基线的 0.62 倍
```

- 系数 **0.6 是产品标定**：文献能给的只有"负反馈存在、有时滞"，给不了这个数；
- 填 0 可以关掉（对照测试用，`hpaNegativeFeedbackGain = 0.0`）；
- 与规则 2（低血清素 ⇒ 半衰期翻倍）方向相反，同时成立时净效果仍偏向"黏住"
  （先 ×2，再最多 ÷1.6）。

**为什么值得加**：没有它，"升得越高拖得越久"，一场争执能挂一整天 —— 那是抑郁模型，不是人。

### 3.2 昼夜反应性（规则 9）

**机制**：HPA 轴的分泌能力本身随时钟变化，凌晨处在谷值，对同样刺激的反应幅度更小。

**实现**（`HormoneKinetics.stressReactivity`）：白天 1.0，22:00 起平滑下调，02:00–06:00 到 **0.85**，06:00 恢复。

**为什么不把晨峰加到 `Hormones.cortisol` 上**（这是个刻意的决定）：

晨峰是"正常的生理高峰"，不是"她现在很紧张"。如果把日间曲线直接画到状态上，
角色会每天早上都"有点紧绷"，晚上都"莫名放松" —— 那不是情绪，那是时钟。
真实作用是**反应性**不同，不是**基线**不同。所以我们只校正增益。

**证据强度说明**：白天不分上午下午，是因为那一层证据互相矛盾
（"上午 vs 下午做 TSST 反应谁更强"的研究结论不一致）。既然不确定，就不编。

| 激素 | 旧半衰期 | 新半衰期 | 依据 | 差多少 |

## 6. 刻意没建模的四条

写在这里，防止后来人以为是漏了。

| 激素 | 文献值 | 为什么不建模 |
|---|---|---|
| **去甲肾上腺素 / 肾上腺素** | 血浆 t½ **2–3.5 分钟** | 管"这一秒的警觉"，我们的粒度是"一条消息"，没有落点；它与皮质醇的行为效果重叠 |
| **褪黑素** | t½ 40–50 分钟；<500 lux 光照即可抑制（甚至 <30 lux） | "困"已经由 `PhysiologyEngine` 的昼夜节律 + 睡眠债承担，再加一条是重复计分。要表达"注意到天黑了"走时间判断，不伪造激素 |
| **睾酮** | 竞争后 15–36 分钟升降，t½ 约 70 分钟 | 我们没有"胜负"事件。硬造一个会变成竞争叙事，与"陪伴"的定位冲突；将来做游戏/比赛场景再加 |
| **CAR（皮质醇觉醒反应）** | 醒后 30–45 分钟 +50–60% | 角色没有"醒来"这个事件（"醒"就是用户来找它）。只作为"晨间反应性"的旁证 |

## 7. 一并修正的一个认知：激素不负责"记住"

旧参数（催产素 24h、多巴胺 2h）实际上让**一次互动影响一整天**。
查文献时发现这混淆了两件事：

| 层 | 负责什么 | 时间尺度 |
|---|---|---|
| 激素 | 当下这条消息怎么回 | 分钟–小时 |
| 记忆 / 关系 | "她记得你上周夸过她" | 天–月 |

把激素调短之后，这个分层才成立：**半小时前的夸奖不再让现在的语气变暖，
但它仍然在世界书/记忆里** —— 该记得的由记忆负责，不该由激素硬撑。

⚠️ 这带来一个**需要在真机上确认**的行为变化：如果记忆与关系线没有真正接到提示词里，
调短半衰期会让角色显得"忘得快"。见第 9 节。

新增的 5 条测试各自钉什么：

1. `默认半衰期就是 HormoneKinetics 里那几个文献值` —— 防"改了政策忘了改表"；
2. `皮质醇越高 回落越快` —— 钉负反馈（比较**走掉的比例**，不是绝对值）；
3. `夜间应激反应更小` —— 钉规则 9，且钉"差别只该一点点"（≤3 点）；
4. `不传时刻时不做昼夜校正` —— 离线回放与线上必须同值；
5. `stressReactivity 白天是一 夜里最低` —— 纯函数边界（含负小时、27 点）。

### 未验证（需真机）

1. **深夜吵架 vs 白天吵架**：同一句重话，凌晨 2 点的皮质醇增量应比上午 10 点少约 2 点
   （18 → 15）。真机上这点差异未必看得出，**主要是"逻辑对"而不是"体感对"**。
2. **亲近感的余韵变短**：45 分钟后"格外黏"应明显退掉。
   ⚠️ 如果退得太干净、像"翻脸不认人"，那说明**记忆/关系线没接上**，不是半衰期的问题。
3. **争执后一小时内平复**：按新参数，被骂（95）1 小时后应落到 67 左右，3 小时后 52。
   若角色在两小时后还明显"记仇"，先查是不是别的地方（关系线/事件残留）在撑。
4. **同一句夸奖连续给**：饱和（`dampen`）仍在，第二次的增益会小；配合更短的半衰期，
   可能出现"第二次夸奖几乎没反应"——这是**预期的**，别当 bug。
5. **跨零点**：23:59 与 00:01 各发一条同样的负面消息，皮质醇增益应分别 ×0.9625 与 ×0.925。
   实际只用来看"有没有报错/有没有跳变"，不必测数值。

## 10. 第二轮（同日）：把 10 条互锁逐条对到文献

第一轮改的是**时程**（半衰期 → 文献值）。这一轮改的是**耦合**：那 10 条互锁里，
哪些有文献支持、哪些只是我的假设。查完的结果是——**新增 1 条（有很强的依据），
其余 9 条只做证据分级，一个数都不动**。

### 10.1 新增规则 10：社会支持缓冲

**依据（这是本次找到的最好一个数字）**

Thorsteinsson & James 1999 汇总 **22 项实验研究、26 组比较、56 个效应量**，
看"实验性地给/不给社会支持"对实验室应激反应的影响：

| 指标 | 效应量 d |
|---|---|
| 心率 + 收缩压 | 0.61 |
| 舒张压 | 0.51 |
| 皮肤电导 | 0.25 |
| **皮质醇** | **0.83** |

也就是说：在实验室里，「旁边有人支持你」对**皮质醇**的影响，
比它对心跳、血压、出汗的影响都大 —— 是这几个指标里最大的一个。
<https://doi.org/10.1080/08870449908407353>

**机制（为什么催产素能压低皮质醇）**

催产素能神经元对下丘脑 **CRH 神经元有抑制性输入**。社会接触释放的催产素，
等于直接掐住 HPA 轴的最上游 —— 不是"心理上感觉好一点"，是物理上少放 CRH。
<https://www.biorxiv.org/content/10.1101/543165v1.full-text>

⚠️ 这条机制是**动物电生理**证据，人类身上只有上面那条行为层的元分析。
两者方向一致，但别把机制当成参数依据。

**实现**

```
催产素 ≥ 65 时：负面事件的皮质醇增量 × 0.75
```

三条边界（写在代码注释里，防止后来人改坏）：

1. **只削负面幅度，不产生正向收益**。聊天不会因为"她开心"就少挨骂 ——
   它不是"陪着就不疼"，是"同样的话在有人的时候扎得浅一点"。
2. `d = 0.83` 是「有支持组 vs 无支持组」的**组间差**，不是"每一分亲近降低多少"。
   拿它当线性系数是误读。
3. **0.75 是产品标定**。文献支持"这一条该有、而且效应不小"，支持不了"就是 0.75"。

**累积顺序**（结果与顺序有关，所以钉死）：规则 5/6 选一个 → 规则 10 缓冲 → 规则 9 昼夜。

最极端一例：Conflict(18) ×1.5（血清素低）= 27 → ×0.75（有人在）= 20 → ×0.85（凌晨）= 17。
比完全不设防的 27 小三分之一，但仍然比默认状态疼。这个梯度是有意的。

### 10.2 证据强度审计：10 条规则分三档

| 档 | 规则 | 依据 |
|---|---|---|
| **机制明确**（可以替参数辩护） | 8 HPA 负反馈 | 糖皮质激素抑制人下丘脑 CRH/AVP（Erkut 1998）+ TSST 60–90min 必回基线 |
| | 9 昼夜反应性 | HPA 昼夜节律明确；**幅度是标定**，且白天不分上下午（那层证据矛盾） |
| | 10 社会支持 | d = 0.83（元分析）+ 催产素抑制 CRH（动物）；**系数标定** |
| **方向有依据，系数标定** | 1 紧张时亲近攒不起来 | 应激抑制催产素系统 |
| | 4 绷着时好事也乐不起来 | 急性压力降低奖赏相关神经活动（reward positivity 研究、Ironside 2018 综述） |
| | 5 脆弱时更疼 ×1.5 | 5-HT 对 HPA 是抑制性的 |
| | 2 低血清素压力黏住 ×2 | 同上 |
| **纯产品假设**（只能替"方向"辩护） | 6 兴奋时对压力钝 ×0.7 | 只有间接旁证 |
| | 3 高催产素血清素回得快 | 没有文献支持这个方向 |
| | 7 饱和 | 借享乐适应最朴素那层（同刺激、基线越高、增量越小） |

⇒ 这张表的意义：后来人想动哪个数字，先看它在哪一档。
**第一档的数字改了要拿文献说话；第三档的随便调，它本来就是设定。**

### 10.3 事件幅度的排序审计（结论：一个数都不改）

Dickerson & Kemeny 2004（**208 项实验室研究**）的结论是：
皮质醇反应的大小由两件事决定 —— **社会评价威胁**（self 可能被他人评判）
与**不可控性**。含评价威胁的任务反应最大；单纯的任务压力几乎不升。
而且"只是有人在旁边看着"**不足以**引发皮质醇反应（社会评价 ≠ 社会在场）。

拿这个框架过一遍我们的事件：

| 事件 | 评价威胁 | 不可控 | 该不该升皮质醇 | 我们的值 | 判定 |
|---|---|---|---|---|---|
| Conflict 争执 | **是**（被指责） | 是 | 升最多 | +18 | ✅ 最大 |
| Rushed 被催 | 弱（隐含不满） | 是 | 升一点 | +10 | ✅ 次之 |
| Neglected 被冷落 | 不是评价（是社会排斥） | 是 | 研究里反应弱且不一致 | **0** | ✅ 保守正确 |
| Praise / Novelty / Intimacy / BeingNeeded | 无 | — | 不升 | 0 | ✅ |

**结论：现有排序与文献框架一致，不改任何数值。** 这一条本身值得记下来 ——
不是每次查文献都要改代码，"查完发现是对的"也是结果。

### 10.4 刻意没做

1. **习惯化**（同一类负面事件反复发生，反应逐次变小）。
   Barthel 2025 的综述说：自然发生的习惯化里，**只有 40% 的研究**观察到第二次 TSST 反应显著下降。
   四成的复现率不足以支撑一条机制。而且实现它要新增"上一次事件类型"的状态字段，
   会动到序列化兼容 —— 代价大、收益不确定，不做。
2. **可预测性**（可预测的应激反应更小）。我们没有"预告"这个事件类型。
3. **恢复期的社会缓冲**（社会支持不只降峰值，还加快回落）。
   规则 10 已经把峰值压低，恢复自然就短，不需要再建模一次 —— 会重复计分。

## 11. 第三轮（同日）：从激素到"这一句该怎么演"

前两轮解决的是 **状态本身**（数值、互锁、半衰期）。这一轮解决的是
**状态怎么变成话** —— 而且刻意不是"让后台 AI 重写人格提示词"。

### 11.1 问题：公式给得出温度，给不出演法

`Hormones.toneDelta()` 目前给出六轴偏移（warmth / brevity / humor /
proactivity / formality / emoji），上限刻意压到 ±16 点。它能说"这一轮暖一点、
短一点"，但给不出这些：

| 场景 | 公式能给 | 真正该演的 |
|---|---|---|
| 用户说"对不起，是我不好" | 暖度 +8 | **先认下自己也有份，别急着安慰** |
| 用户提了一周前那件事 | 无（记忆不在激素里） | **顺口带一句"你上次说的那个"，不展开** |
| 她刚被别的事弄烦 | 皮质醇高 → 短 | **这轮不开玩笑，也别解释为什么不开** |

第三行尤其关键：状态说"短"，但"短"可以是冷淡、也可以是体贴。
**这个区别不在数值里，在场景里。**

### 11.2 三种做法的取舍（为什么只给它一句话）

**做法一：让后台 AI 每轮重写前台的人格提示词。**
- L0–L2 的逐字节稳定前缀立刻失效，KV-cache 全废（每轮贵一倍以上）；
- 两套提示词互相矛盾时没人知道该信哪套；
- 离线没法断言 —— 等于把人格交给一个不可测的组件。

**做法二：让后台输出 `{"warmth": 0.2, "brevity": 0.7}`。**
- 与 `toneDelta()` 打架：两份真相，而且公式那份至少有半衰期和文献背书；
- 它凭什么比公式准？模型没有比公式更多的信息。

**做法三（采用）：只让它写一句"这一句怎么落地"。**
- 不碰 L0–L2，只挂在 L3 末尾 → 前缀的 KV-cache 不受影响；
- 一句话可断言：长度、禁词、数字、防抖全部能离线测；
- 它补的正是公式缺的那块 —— **场景知识**，不是数值。

### 11.3 管线

```
PersonaRuntime.currentState().hormones.portrait()      ← 行为档位（不含激素名）
        │
        ├──→ DirectorPrompt.build(hormonesPortrait, lastPerformance)
        │        后台模型 = 「导演」：不是聊天的人，只说这一句怎么演
        │
        ├──→ DirectorParser.parse → "performance": "…" | null
        │
        ├──→ PerformanceGate.accept(...)                ← 四类闸
        │        Accepted → AppContainer.performanceValue
        │        Rejected → 只记日志，不影响本轮的事件
        │
        └──→ AssistantPromptBuilder.build(performance)
                 → PersonaAssembler.renderState（判 20 分钟有效期）
                 → L3 末尾多一段「## 这一句怎么演」
```

**两条独立性**（都刻意设计）：
1. 指导被拒**不影响**事件生效，事件被 `DirectorGate` 拒也不影响指导；
2. 指导过期就静默退回旧模板句 —— 判错方向是安全的（最坏只是不注入）。

### 11.4 四类闸（`PerformanceGate`）

| 类别 | 拦什么 | 为什么 |
|---|---|---|
| 术语 | 皮质醇 / 多巴胺 / 血清素 / 催产素 / 激素 / nmol / ng/mL | 前台读到会立刻出戏，用户会觉得"被测量" |
| 数值 | **任意阿拉伯数字**（新增：正则，不只是"数值"两字） | 模型写的是 `紧张度 0.3`，里面没有"数值"两个字 |
| 系统语 | 检测到 / 系统 / 模型 / 提示词 / 指令 / 参数 / 评分 / 设定 | 否则角色会开始解释机制 |
| 元语言 | 扮演 / 人设 / 角色扮演 / AI / 人工智能 / 虚拟 | 当着演员的面念导演笔记 |
| 索取 | 安慰我 / 别离开 / 不理我 / 你必须 / 你应该 | §4.6：情绪操纵比没有指导更糟 |

另外三条：
- **长度 ≤ 60 字**：L3 整段只有两三句，指导比状态还长会喧宾夺主
  （"提示词里最长的那段最容易被遵守"）。
- **与上一轮一字不差 → 拒**：重复注入等于要求"再演一遍"。
- **激素没变且上一条未过期 → 拒**（"激素没变，沿用上一条"）。
  这条是防"同一个状态演两遍越演越夸张"——真机上最难发现的一条。

### 11.5 为什么 `portrait()` 不含激素名

`Hormones.portrait()` 返回的是纯行为档位：`绷着，容易烦` / `有点紧` /
`很想靠近` / `想多聊两句` / `情绪底子薄` / `情绪偏低` / `来劲` / `提不起劲` /
`平稳`。

⚠️ 原因是**实测过**：后台模型看到"皮质醇偏高"会照抄进 `performance`，
抄了就撞禁词，然后整条被拒 —— 白跑一次调用。
所以宁可只给它行为词，让它没得抄。

### 11.6 有效期 20 分钟

比最短的那条行为半衰期（多巴胺 30 分钟）略短。理由：
- 一条挂一天的指导会变成**新的人设**（它比状态更具体，更容易被模型当锚）；
- 状态半小时就换了一轮，20 分钟后那条话已经不对应当前场景了。

### 11.7 刻意没做的

1. **不给自定义角色接这条路**。自定义角色走的是"整条替换装配器"那一支，
   L3 本来就不出现，硬塞一句指导会和她的人设打架。要接得先让 L3 进得去。
2. **不做"每轮都生成"**。提示词里明确写了"大部分轮次写 null"——
   高频生成会让指导从"点睛"变成"底色"，也会把后台调用成本翻倍。
3. **不让它改状态**。状态仍只由 `HormoneEngine` / `PhysioPrompt` 改。

### 11.8 一并修掉的一个 bug

L3 的状态句原来是四个 `append()` 直接拼的，`mood≥65` 与 `energy≥70`
同时成立时会拼成 **「你现在心情不错精神很好」**（没有顿号）。
前台模型读这种句子会把它当成一个词，语气跟着变形。
现改为 `buildList{}.joinToString("、")`，单条时输出不变。
