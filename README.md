# PocketAgent

一个安卓上的 AI 伴侣 —— 住在你自己的手机里，用你自己的 Key，没有服务端。

她不是"问答框 + 语音播报"：人格、身体、记忆、时刻感都在本地跑，
模型只负责说话。换个模型，她还是她。

## 现在能做什么

### 人格不是一个提示词

- **激素**：多巴胺 / 血清素 / 催产素 / 皮质醇四条轴，按小时衰减，事件推动。
  她不会因为你夸一句就立刻开心，也不会因为一次争吵就记恨整天。
- **生理**：作息、睡眠债、一天里的精力曲线；熬夜到凌晨她确实会困。
- **周期**：可选。只影响精力与一点激素，**刻意不碰血清素** —— 不做"经期＝情绪化"的刻板印象。
- **体检报告**：基础信息、血常规、生化、甲功、心电图、影像、营养，按真实体检结构填；
  另有"报告里不会写"的部分：痛阈、怕针、旧伤、气味、体温偏好。
- **意愿**：低到一定程度可以拒绝（默认关闭，设置里有开关）。
- **世界书**：设定与事实分两套入口，事实只能补、不能改设定 —— 这是防"设定塌成流水账"的机制。

### 三种活法

| 模式 | 她在干什么 |
|---|---|
| 角色 | 陪你说话。语气、称呼、旧账都跟着当前状态走 |
| 工作台 | 干活。有工作区、权限档、独立的历史记录 |
| 在场 | 有自己的今天。会看网上的东西，会主动发一句 |

三种模式的会话历史**互相隔离**，不会串。

### 动手

33 个内置工具，按需挂载（不是一次性全塞给模型）：

- **屏幕与手机**：读屏、截图、点击、滑动、输入、按键、改设置、停用应用
- **文件**：读、写、列目录；Office 三件套 `pptx / docx / xlsx`（含二进制写链，不是假文件）
- **图像与文档**：转格式、缩放、PDF 转图、图片合并成 PDF
- **压缩包**：打包、列表、解包（含 zip-slip 防护）
- **图表**：柱状／折线，纯 Kotlin 画 PNG，不依赖外部库
- **联网**：`web_search` / `web_fetch`；默认拦内网与本机，设置里可开「超级网络权限」
- **提醒与朗读**：闹钟提醒、TTS 朗读、听写（只在你要的时候开麦克风）

### Linux 工作区

三档后端，谁可用用谁：**root 容器（chroot）→ Termux → 内置 Python**。

- root 档能装包、能真断网、`/work` 与宿主工作区双向绑定
- 内置引擎只跑 `python3 -c`，纯标准库，装不了包
- 一次性的根文件系统可以从设置里点一下装（Alpine，约 3.6 MB）

### 语音

- BreezeBlue（官方云端 + 自建 vLLM 两条）与 ElevenLabs 系协议；OpenAI 兼容 TTS
- 回复上屏前先把语音落盘，点开就是本地播放，不重复计费
- 语音条 60 秒上限、可多条；下面跟纯台词，标签不会露到界面上
- 文件卡片点开**在应用内预览**：图片、PDF、Office 文字预览

### 记忆

- 抽取 → 打分 → 相关性检索，三级保真（精确 / 模糊 / 遗忘）
- 情绪强度会拖慢遗忘曲线；重要的事不会因为过了两周就蒸发

## 架构

- **纯 Kotlin 逻辑层**（`:personalogic` `:memorylogic` `:filelogic` `:voicelogic` `:rootlogic` `:agentlogic` `:mcp` `:modelrouter` `:keymgmt` …）
  不碰 Android 框架，可以在 PC 上离线跑测试
- **Compose UI 层**（`:app`）
- **Provider 层**：OpenAI 兼容 / Anthropic / Gemini / 本地 / TTS
- **无服务端**：没有我们的服务器，Key 只存在你自己的设备上（加密存储）

看起来"多余"的模块划分只有一个理由：**能在没有手机的情况下验证**。

## 系统要求

- Android 10 及以上（targetSdk 36）
- root 档需要 Magisk / KernelSU / ReSukiSU 授权（应用分身要单独授权）
- 不需要 root 也能用：内置 Python、Termux 档、以及全部办公/图像/联网工具

## 安装

从 Releases 下 APK 直接装，或自己构建：

```bash
cd android
./gradlew :app:assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk
```

debug 包约 143 MB（未混淆、双 ABI）。首次启动会让你填 Key：OpenAI 兼容、Anthropic、Gemini 任选。

## 安全边界

- 工具按权限档分级，默认第 0 档只给读取类能力
- 联网工具默认拒绝本机与内网地址（含云元数据端点），跳转每一跳都重新校验
- 解包强制路径规范化，防 zip-slip
- 语音标签只送往语音合成，用户可见文本会切干净
- **不做**"读完免责声明就解锁一切"的设计：能碰什么由档位决定，不由话术决定

## 隐私

- 没有账号，没有遥测，没有云端同步
- 对话、记忆、语音缓存全部落在应用私有目录
- 唯一的出网是你的模型请求与你明确触发的联网工具
